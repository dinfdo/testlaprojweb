LeG - Learning by Playing Web Games

Bun venit in LeG! Aplicatia ta nostalgica in stil Windows 95 prin care inveti, jucandu-te, componentele unui calculator. Asambleaza un PC, identifica piese, asociaza specificatii si infrunta provocarea finala in mini-jocul cu timp limitat.

6 jocuri progressiveDrag & drop, identificare, match, cabluri, mini-quiz, istorie.
Enciclopedie hardwareCPU, GPU, RAM, SSD/HDD, PSU, periferice.
Leaderboard cu RSSClasament global exportat ca feed RSS 2.0.
3 niveluri dificultateProgresul tau este salvat per joc.

Stack: PHP 8.2 (vanilla MVC), SQLite, JWT, AJAX, HTML + CSS + JS.
