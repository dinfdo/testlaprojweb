# LEG Project

Proiect web cu structură de front-end și API în PHP.

## Structură proiect

- `public/` - pagini HTML, CSS și JavaScript
- `api/` - endpoint-uri PHP pentru autentificare, componente, joc și clasament
- `config/` - configurare conexiune la baza de date
- `database/` - schema și date de seed pentru baza de date

## Instrucțiuni

1. Configurați serverul web și PHP.
2. Actualizați `config/database.php` cu datele de conectare.
3. Importați `database/schema.sql` și `database/seed.sql` în MySQL.
4. Accesați paginile din `public/`.
